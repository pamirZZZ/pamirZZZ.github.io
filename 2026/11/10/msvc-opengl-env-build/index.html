Visual Studio 2022 openGL环境配置

发表于2026-11-10|更新于2026-11-10|指南
|浏览量:

GLUT安装

GLUT下载地址

  • 定位到VS2022根目录下的 include 文件夹

位置一般为：xxx\Microsoft Visual Studio\2022\Community\VC\Tools\MSVC\14.44.35207\include

p.s. 具体的版本号会有所不同

在include文件夹创建一个名为 gl 的文件夹，放入下载压缩包中的 glut.h 文件

  • 定位到VS2022根目录下的 lib 文件夹

即：xxx\Microsoft Visual Studio\2022\Community\VC\Tools\MSVC\14.44.35207\lib

打开 x86 文件夹，放入 glut.lib 和 glut32.lib

  • 打开系统文件夹

32位系统对应 C:\Windows\System32

64位系统对应 C:\Windows\SysWOW64

放入 glut.dll 和 glut32.dll

在VS2022中新建控制台应用

打开 项目菜单 -> 管理NuGet程序包

搜索并安装 nupengl ，一共有两个文件，安装其中一个另外一个会默认安装

注意每次新建一个需要用到glut的项目都要安装一次

至此已完成glut的安装

GLFW安装

GLFW下载地址

选择 64-bit Windows binaries （根据VS版本选择）

打开下载的文件夹

glfw-3.3.6.bin.WIN64\include\GLFW

将 glfw3.h 文件放到 xxx\Microsoft Visual Studio\2022\Community\VC\Tools\MSVC\14.31.31103\include\GLFW 文件夹中（新建GLFW文件夹）

打开lib-vc2022文件夹 glfw-3.3.6.bin.WIN64\lib-vc2022

将 glfw3.lib、glfw3_mt.lib、glfw3dll.lib 放到 xxx\Microsoft Visual Studio\2022\Community\VC\Tools\MSVC\14.31.31103\lib\x86

将 glfw3.dll 放到 C:\Windows\SysWOW64（根据系统位数决定）

至此已完成GLFW的安装

GLAD安装

GLAD下载地址

作如下的选项，点击Generate

选择生成的zip文件下载

将 glad\include 中的两个文件夹复制到 xxx\Microsoft Visual Studio\2022\Community\VC\Tools\MSVC\14.31.31103\include

glad\src的glad.c文件不需要做额外的放置

如果项目中需要用到GLAD，则把glad.c复制到源文件目录

至此已完成GLAD的安装
